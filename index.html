01. About

I started out as a Python backend developer building Django and Flask apps, and moved into AI through my M.Tech in Data Science. Today I work end to end: from data collection and model training to retrieval pipelines, APIs and the interface on top.

I like systems that are measurable and reliable: hybrid retrieval with reranking and citations, automated evaluation for LLM answers, and detection models benchmarked across architectures before one goes to production.

Outside of models, I build small tools that remove busywork, like browser extensions that autofill job applications or extract text, all privacy-first and running locally.
